# Gautam — Data Analyst Portfolio

A simple, free-to-host, no-build portfolio website.

## Files
- `index.html` — website content
- `style.css` — design and responsive layout
- `resume.pdf` — add your own resume here

## Before publishing
1. Replace the GitHub, LinkedIn, Google Drive and email links in `index.html`.
2. Add your `resume.pdf` in this folder.
3. Replace project links as you complete projects.
4. Push the folder to a GitHub repository.

## Recommended free hosting
GitHub Pages is a good first option because this is a static HTML/CSS/JS portfolio.
Later, the same project can also be deployed on Vercel.
